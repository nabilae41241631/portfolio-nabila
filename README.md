# Portfolio Nabila Istiya Arum Zahfa

Website portfolio pribadi untuk menampilkan profil, pengalaman, dan sertifikat.

## Tentang Saya

Mahasiswa Teknik Informatika Politeknik Negeri Jember semester 4 dengan fokus pada Quality Assurance dan pengujian perangkat lunak.

Memiliki pengalaman:

* Manual Testing
* Penyusunan Test Case & Test Scenario
* Bug Reporting
* UI/UX Design dasar

## Fitur Website

* Halaman About (profil & fokus bidang)
* Halaman Experience (pengalaman project)
* Halaman Certificates (sertifikat)
* Halaman Contact (WhatsApp, Email, LinkedIn, Instagram)

## Teknologi

* Laravel
* PHP
* HTML CSS
* MySQL

## Cara Menjalankan

1. Clone repository
2. Jalankan composer install
3. Copy .env.example ke .env
4. php artisan key:generate
5. php artisan serve
